# definitions-open-mower
Collection of JSON files for the open mower project

## Editing a service definition

Edit the `*_service.json` file and commit it - that is all. The Go clients in
`golang/` are generated from these schemas and checked in, so the CI regenerates
them and commits the result back to your branch; you do not need a Go toolchain.
The firmware generates C++ from the same JSON at build time (via its `services/`
submodule), so nothing else has to be generated by hand.

Only when CI must not commit for you - a schema change pushed straight onto the
default branch, or a pull request from a fork - run `cd golang && go generate ./...`
and commit the clients yourself. `golang/README.md` has the details.
